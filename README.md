Bad UI Evil Calculator

Bad UI Card, deliberately frustrating calculator where buttons fall when you click them, 
and bounce around the screen under gravity. To enter a number or operation, the user has 
to find the moving label, and drag it into the display.

Features:
- Gravity, buttons fall and bounce around the lower bounds of the calculator
- Drag to use, drag labels into display to enter them into the calculator
- Constant motion, keeps labels constantly moving to make it more inconvenient
